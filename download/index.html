How to install

Android

  1. Tap Download for Android and wait for the file to finish.
  2. Open the downloaded file (find it in your notifications or the Downloads folder).
  3. If Android asks, allow Install unknown apps for your browser, then go back.
  4. Tap Install and open the app. Later versions arrive through the app's own update prompt.

Windows

  1. Click Download for Windows and wait for the .msi file to finish.
  2. Double-click the file. If SmartScreen warns, choose More info, then Run anyway.
  3. To remove it, use Settings > Apps.
